# Car Dealership Inventory System

A full-stack car dealership inventory management system built using JavaScript, Node.js, Express, MongoDB, React and Tailwind CSS.

## Features

- User registration and login
- JWT authentication
- Role-based admin access
- Add vehicles
- View vehicles
- Search vehicles
- Purchase vehicles
- Inventory quantity management
- Delete vehicles for admins
- MongoDB persistence
- RESTful API
- Automated backend tests
- Responsive React frontend

## Tech Stack

**Backend:** Node.js, Express.js, MongoDB, Mongoose, JWT, bcryptjs  
**Frontend:** React, Vite, Tailwind CSS  
**Testing:** Jest, Supertest  

## Project Structure

```
Car-Dealership-Inventory/
├── backend/        
└── frontend/       
```

## Getting Started

### Backend
```bash
cd backend
# Fill in your MONGO_URI and JWT_SECRET in .env
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

## Running Tests
```bash
cd backend
npm test
```
